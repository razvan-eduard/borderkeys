An Android keyboard that requests zero permissions and contains no code capable of opening
a network connection. Word prediction is a deterministic engine — a compact trie plus
n-grams — written in C++ and running through JNI, not a language model.

Nothing downloads at runtime. Dictionaries and language packs are either inside the APK or
imported by you from a local file. There is no telemetry, no crash reporting, no account
and no sync. Clipboard history and the personal dictionary live in a SQLCipher-encrypted
database and are excluded from system backup and from device-to-device transfer.

* No permissions at all. Haptic feedback uses the API that needs none.
* The typing surface is a custom View drawing on a Canvas — no Compose and no XML layout
  inflation in the keyboard process.
* Several languages active at once, with no manual switching. Mixing two languages in one
  sentence is the normal case, not an exception.
* Notices when a correction was made under the wrong language and offers the word back, or
  fixes it automatically — your choice — landing on the field's own undo history like any
  other edit.
* Swipe typing decoded geometrically on-device, with an optional radial menu: pause
  mid-swipe, without lifting, to open a ring of alternatives and slide onto one, or onto
  Cancel in the centre, all in one continuous stroke. Off by default.
* A names dictionary built from Wikidata (CC0), so a name capitalises correctly
  mid-sentence instead of only at the start of one.
* Alternate physical layouts — AZERTY, Dvorak, QWERTZ, ClearFlow, KasRoz and Toki Pona —
  alongside QWERTY, for every bundled language.
* A personal dictionary you can see and edit: every learned word has a Forget and a Block
  right beside it, not a black box.
* A row of quick actions for copy, paste, select-all and more, extendable with your own
  macros.
* Built-in themes, full manual colour control, and a library to save, import and share
  your own.
* Backup and restore everything this keyboard has learned and configured to a single file
  you control. Nothing syncs anywhere on its own.
* Private mode is automatic in password fields and whenever an app sets
  IME_FLAG_NO_PERSONALIZED_LEARNING: no learning, no clipboard history, no personal
  dictionary.
* Works with any installed password manager through the platform's inline autofill
  suggestions. The keyboard cannot read their contents — the platform guarantees that —
  and never sees your password.

This is the "core" build: it contains no machine-learning model of any kind, and no
code that could run one. A separate "BorderKeys +" is published alongside it for anyone
who wants the on-device text assistant; the two can be installed at the same time.
